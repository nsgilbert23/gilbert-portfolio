## Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/nsgilbert23/gilbert-portfolio.git
   cd gilbert-portfolio
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Create a production build:

   ```bash
   npm run build
   ```
